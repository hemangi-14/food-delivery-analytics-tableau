# Food Delivery Analytics Dashboard using Tableau

## 📊 Project Overview

The Food Delivery Analytics Dashboard is an interactive Tableau project designed to analyze food delivery operations, restaurant performance, customer ratings, pricing patterns, and delivery efficiency.

The project converts raw food delivery data into meaningful visual insights using Tableau dashboards, calculated fields, filters, KPIs, and different types of charts.

The dashboard helps understand how restaurants, cities, food categories, prices, ratings, and delivery performance are connected.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze overall food delivery performance.
- Identify cities with high restaurant and order activity.
- Analyze restaurant performance using ratings and orders.
- Study delivery time and delivery efficiency.
- Analyze customer ratings.
- Study the relationship between price and ratings.
- Identify popular food categories.
- Compare delivery partners.
- Analyze order trends over time.
- Provide interactive dashboards for business decision-making.
